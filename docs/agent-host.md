# Agent host

The external API, MCP, and CLI client for agents driving Dinkster shared
sessions is maintained in
[`Kosinkadink/dinkster-agent-host`](https://github.com/Kosinkadink/dinkster-agent-host).

Dinkster-Frontend retains the product-side shared sessions, collaboration
protocol, credentials, permissions, presence, and run attribution that the
external client uses.
