# Advanced controls

Nodes keep uncommon tuning controls in a collapsed **Advanced** section. Expand
the section to edit them. Advanced stays below all ordinary input and output
rows whether collapsed or expanded. A tinted background and dark border enclose
the complete expanded rows, including labels, controls, and connection pins.

Collapsing the section hides its controls and unconnected pins. Connected inputs,
outputs, and widget outputs remain visible as proxy sockets on the disclosure so
their links stay attached. Expanding Advanced restores every link to its exact
socket row without changing graph endpoints. The header remains available to
pointer and keyboard navigation, and a marker indicates hidden modified values.
